# WeatherNow React

A React and Vite version of the WeatherNow application. It looks up Romanian
localities and displays current weather conditions and a seven-day forecast
using the Open-Meteo geocoding and forecast APIs.

## Requirements

- Node.js 18 or newer
- Internet access for the weather and geocoding APIs

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create and preview a production build:

```sh
npm run build
npm run preview
```

The original HTML/CSS/JavaScript project is unchanged; this React version is
provided as a separate project.
